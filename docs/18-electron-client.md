# Electron 客户端

本机大文件上传受阻时，手动 ad-hoc 构建流程可用 `draft_assets_only=true`，从已存在标签在 CI 验收后仅上传现有草稿；完整六个附件保持同次构建，公开版本拒绝覆盖。签名正式流程不变，最后发布仍由操作者按授权执行，见 CONTRIBUTING。

沟通列表使用 38px 身份头像；单聊始终使用员工颜色和两字字形，群聊按稳定会话 ID 分配已有身份色。自定义候选使用共享原生 Popover 顶层定位，跨越正文滚动裁剪并按窗口空间选择上下位置；视觉与生命周期见 docs/06。创建/编辑表单仅由关闭/取消或提交退出，textarea 变高时顶部稳定，避免背景松手误关闭；不增加宿主桥或修改业务执行语义。

任务不再展示团队标签；员工 Tab 通过共享 workspaceAgents 投影排除 status=deleted 的来源员工，历史协作消息与调用证据仍保留。独立群聊右侧展示当前成员，姓名打开详情，控制台图标打开最右侧日志；窄窗口成员与控制台都有明确关闭入口，聊天草稿与阅读状态保留。

协作读模型以消息/事件为主线，按 sourceMessageId 或唯一的已有定向消息、Dispatch/Trace 引用关联真实派工；不按正文、名字或时间猜测，不回填历史。deliveries 明示投递当前状态，history 保留每次执行与重试的实际时间，经理协调为全流程范围。CLI 保留完整投递/执行事实、验收关联及有界文件 ID/名称引用（files 最多8项、fileCount 为总数）；完整文件列表用 artifacts 查询。已知员工交接结果信封从 rawResponse 提取已记录的报告正文，去除重复结构化结果，原始消息和控制台事实不变。客户端协作区展示成员总结、沟通和关键人类状态，保留单一“本轮控制台”入口；不自动附加投递状态、技术失败/重试通知、验收文件清单或平台验收说明。长消息全文一次渲染 Markdown，超过10行仅收起区域，展开不重建 DOM，Run 内保留阅读状态。控制台无顶部错误摘要，失败记录在日志内标红；员工状态按自己的最新 Trace 显示错误/执行中/正常，重试成功后清除旧错误。未验证事项保留员工原文，不自动判定交付质量；存储、调度、模型输入和人类确认规则不变。

任务协作时间线合并同一 Run 的全部 Message、实际 Dispatch 与协调事件。接收人表示处理对象，不表示私密级别：经理派工指向接手员工，工作交接指向经理，咨询/答复保留双方，没有处理对象的发言只显示发送者。sourceMessageId 仅关联同 Run 来源消息，正文与首个实际投递合并；同源额外投递归入同一消息；无法用已存引用关联的投递独立注明，不猜测历史来源。显示节点、尝试次数、重试/错误和真实投递状态；发言与接手执行提供独立控制台入口。任务确认、取消、暂停、恢复等事件按时间保留，不输出原始 Provider 帧或提示词。

角色侧栏入口与现有导航共用 compact.css 的 SVG 蒙版机制，显式提供人物名牌轮廓，随 currentColor 适配选中状态及主题；缺失蒙版不能以实心方块充当图标。共享 NAVIGATION 提供角色的隐藏、重载保留及默认恢复；展示变更不增加宿主接口或 CLI 能力。

平台历史 MCP 以打包 Electron 的 Node 模式运行，Codex 适配器只向该 MCP 子进程传入 Bridge 完整 env；历史服务 required，初始化失败不静默丢工具。协作流不再固定附加验收说明或显示停止答疑按钮，经理结论按普通消息排列；未归档输入、人类确认与内部取消/审计规则保留，气泡沿用共享紧凑间距。

图标资源约定：web/icons/application.png 保留用户原始字节；build-app-icon.cjs 用 macOS Swift/CoreGraphics 与 sips/iconutil 生成干净的 application-ui.png、带 100/1024 透明边距的 application-dock.png 及同尺度 ICNS。菜单栏单独使用无底板的 trayTemplate.png/@2x 单色 A 模板，由 macOS 适配明暗和选中状态，不强制白色、不将整张彩色图变成模板。无浏览器、网络、新包依赖或宿主桥；生成是开发工具，发布读取已生成资源。

控制台提示词完整呈现已脱敏系统层与本轮输入，底部为该调用已确认原生会话 ID，不包含 Provider 隐藏上下文。工具审计详情与空进度摘要不展示；仅按 Trace/原生调用 ID 归并重复阶段，单次调用内相同输入只显示一次，不同调用即使参数相同也各自保留输入输出，无 ID 不猜测合并。团队/工作流支持同行搜索，任务归档/新建进入搜索行，目录操作区上移。图标统一不引入通用桥。

任务/沟通控制台通过共享投影隐藏无内容的常规生命周期与 Provider 状态通知；正文、思考、工具、提示词和异常保留。过滤只影响呈现，不删除原始审计、诊断或原生会话绑定；分页仍以原始事件为准，CLI/API 不变。

任务事件自带的 Provider 类型前缀与沟通无前缀事件统一识别，交接保存确认不再单列。

团队/工作流顶部复用共享目录工具栏和间距；compact.css 只移除列表顶边框，保留条目分隔。标题语义保留但不重复显示，创建命令和宿主接口不变。

沟通右侧半屏控制台使用共享 renderer，提供成员切换、真实 thinking/text/tools、提示词、失败与分页。附件用浏览器文件选择和认证 HTTP 保存到会话目录，下载保留原名；不新增通用宿主桥。compact.css 仅调整间距字号，市场头像沿用员工颜色。模型真实专项在源码隔离客户端执行，安装包另以隔离 HOME/受控 CLI 验证。

任务工作根独立于应用数据：安装版和开发版均默认 ~/agentforge，无 desktop/web 子目录；已保存工作根优先，已有任务路径不搬动。新 Task UUID 避免共享工作根的跨实例目录碰撞。CLI 源码/安装版都只发现运行中的客户端，无 --target/Web 回退；会话统一 ~/.agentforge/cli-session.json，旧安装版需重新登录。CLI 安装入口仅客户端显示。

员工、插件/MCP 市场复用共享搜索/卡片/删除命令；桌面通过 compact.css 保持紧凑尺寸，隐藏重复页标题不产生工具栏前空白。删除确认使用现有应用弹框，不增加宿主进程桥或系统弹框。

Electron 使用本仓库 renderer 界面，宿主代码位于 `apps/electron/`。

控制台提示词按调用开始时间随分页排列，不固定在最新片段上方；活动成员使用蓝色强调。协作记录和私聊/群聊复用共享语义色，桌面保留紧凑记录，颜色不替代状态文字或领域事实。

## 运行与数据

主进程启动自己的 loopback 子服务，随机端口与实例 ID 经 IPC 回传并匹配。子服务要求 IPC 父进程和 bootstrap 信息，父进程断开即退出，没有独立 Web 启动或部署配置。

| 实例 | 默认数据根 |
| --- | --- |
| 安装版 | `~/.agentforge/desktop/` |
| 源码开发版 | `~/.agentforge/desktop-dev/` |
| 日志 | `~/.agentforge/logs/<实例标识>/` |

数据根包含业务 SQLite、认证数据库、Runtime 私有配置、插件/MCP 和 Run 文件。ready 前将 Electron userData/sessionData 指向数据根下的 `browser/`（Cookie、localStorage、缓存、偏好），日志与崩溃目录分别为 `electron-logs/`、`crash-dumps/`。源码测试可用 `AGENTFORGE_DESKTOP_DATA_ROOT` 隔离；工作目录设置仅影响任务文件。

不自动搬迁旧 Chromium 登录态，升级后可能需要重新登录；原认证数据库不删除。浏览器自身目录、Provider CLI 的 ~/.claude 或 ~/.codex 以及用户主动下载导出的文件不属于 AgentForge 配置，不擅自移动。

旧默认位置仍有数据而新目录为空时拒绝静默新建；一次性搬迁脚本 `scripts/migrate-data-home.mjs` 先演练，显式 `--yes` 后复制校验并保留备份。清理仓库不执行此脚本。

## 宿主边界

窗口开启隔离与 sandbox，禁用 renderer Node。导航限定当前实例 origin；外链通过宿主处理。preload 只提供关闭偏好、CLI 安装、受限复制和打开当前 Run 工作目录等封闭能力，没有通用文件/进程接口。

主进程拥有确认窗口、菜单栏、关闭/退出和自有子进程。设置可选择关闭窗口退出或保留菜单栏，Cmd+Q 退出。退出会停止自有后台。

启动后台前一次捕获登录 shell 环境，限时、可取消，内部启动字段受保护；日志不记录完整环境。

## 界面

员工、插件/MCP 市场采用自适应列数的卡片；员工状态在创建/编辑均可选，扩展搜索器纵向排列。插件安装直接整批处理来源，详情上方概要、下方 Skill/Subagent/Hook 标签页；共享命令，不增加原生弹框或通用桥。

web/ 是客户端 renderer 源码。服务始终为 HTML 加入 compact.css，不按 User-Agent 切换模式。设置始终包含 CLI 分类，宿主不可用时明确报错。

控制台工具收起时显示已记录的 Bash 命令或 Read/Write 文件路径；成功 Read 展开显示 Done，Write 展开显示写入文本。摘要与正文复用受认证、完整性校验的已脱敏内容，失败与缺失信息不伪造成功。

工作目录只保留当前文件与 CHANGE，使用同一目录树呈现；交付版本页面已移除，后台 Artifact 历史保留。任务标题左侧提供返回列表按钮；控制台不重复显示协作 `message.sent` 正文。提示词现状见 [组装说明](22-prompt-assembly.md)。

当前文件支持下载完整字节：共享界面通过认证 HTTP 取得文件后交由浏览器下载；桌面工具栏保持下载/刷新靠右，不新增通用宿主文件桥或放宽权限。安装包测试监听 Electron 原生 DownloadItem 完成事件，并只把保存位置重定向到隔离测试目录核对文件。

## CLI 与打包

安装版启动时默认安装，设置 → 命令行 CLI 可修复用户级 `~/.local/bin/agentforge` 和受管 PATH 块；不需要全局 Node。安装版 CLI 读取私有 endpoint 并验证当前实例 ID，失效不回退 Web。

`npm run package:mac` 输出 Apple Silicon DMG/ZIP。当前要求 macOS 13+，采用 ad-hoc 签名，未经过 Developer ID 签名或 Apple 公证；发布上传 SHA-256 清单。构建和验证不得包含操作者的账户、凭据或业务数据。

品牌样式使用 docs/06 的蓝/青/紫共享 tokens；员工可用与 Runtime 支持标签统一品牌蓝，全部目录空态明确共用背景、虚线边框、圆角与间距。侧栏、Dock/ICNS 使用用户原图派生的干净彩色资源，菜单栏使用独立无底板单色模板，随系统明暗变色。仅视觉变化，无 HTTP/CLI 或任务状态变更。

## 默认命令行集成

Mac 安装版从持久位置启动时默认执行用户级 CLI 安装，复用现有受管安装器：`~/.local/bin/agentforge` 与 zsh/bash 的 PATH 标记块。不使用 sudo，不覆盖其他命令、链接或并发修改；不支持的 Shell/位置及安装失败保留设置页的状态与重试。源码模式及临时卷不自动安装。默认安装无需额外确认弹窗；用户在设置中仍可修复安装。

宿主通过正式认证端点生成父会话关联的 CLI 授权并发布在私有实例目录，登录/退出/服务重新连接时同步；CLI 不读浏览器文件。授权契约见 docs/14。

设置页 Runtime 在原页面默认折叠，展开保留编辑 DOM；宿主 h3/h4 的字号层级适用于仓库访问及 Runtime。下拉模型标签与思考档位显示首字母大写，但值保持 Provider 原始值；设置布局不改变 CLI 协议。

设置中的 Runtime 与仓库访问使用紧凑二级分组与分隔行；主/子标题保持递减。任务中心和归档列表直接显示可用操作，不再折叠进“更多”；保留原确认、禁用条件及 HTTP/CLI 协议。桌面密度只由 compact.css 覆盖。

新建任务为内容优先的 task-create-modal：正文随窗口在六至十二行之间调整，最高十二行，超出文字在输入框内滚动；验收标准默认折叠可空，团队/流程底部同排，目录仅小字。不再展示执行说明或经理/节点详情；底部操作固定、短窗口正文滚动，现有创建/启动与 CLI 字段不变。

工作目录的「打开」调用零参数 `openWorkspaceDirectory`。宿主仅接受本窗口主 frame 的当前 `/runs/:id` 页面，通过同一登录 Session 的认证 workspace summary 读取该 Run 的绝对目录，核对 Run ID、页面未切换和真实目录后调用 shell.openPath；不接受 renderer 提供的路径。未登录、目录不可用或系统打开失败明确报错。此能力不扩展 CLI/HTTP 协议。

任务中心搜索区与任务列表左右外缘对齐，搜索区到列表保留8px间距，当前任务/空搜索/归档列表一致；桌面compact.css去除full-panel的重复内边距。仅展示调整，无HTTP/CLI协议变化；test-runtime-settings覆盖两主题宽窄窗口。

目录空态统一由 `web/styles.css` 的 `.directory-empty` 维护，跨满列表/卡片行并对齐左右边缘，内边距14px 16px；沟通选择器跟随其列表宽度。实时同步移至登录信息旁，窄侧栏保留可访问的状态圆点，顶栏不重复。仅呈现变化，无 CLI/API 协议影响。

应用图标保留用户原始 PNG；侧栏使用清理边缘的彩色圆角图，Dock/安装包使用相同的 824/1024 图形比例及透明留白，避免图标过大或白色底板。顶部菜单栏使用独立的 18pt/2x 单色 A 模板，随 macOS 明暗背景和选中状态变色。详见 web/icons/README.md；无 CLI/API 或任务协议变化。

设置 → 更新 → 应用更新和应用菜单“检查更新…”提供正式版检查、下载进度、发布链接与下载后安装。启动20秒/每6小时自动检查，Beta不参与；下载和安装均由用户触发。Developer ID签名版本支持原生重启安装；ad-hoc版本提供已校验DMG手动安装。重启需父子私有IPC的原子空闲锁，不暂停/结束任务；不增加通用文件桥或CLI能力。完整架构、发布附件与签名要求见 [应用更新](24-desktop-updates.md)。

应用更新只在设置/updates 区域展示版本、状态、进度和按钮；移除全局通知卡及其订阅入口。后台检测保留，进入更新区域读取最新状态并订阅变化，不自动切换页面。此调整无 CLI/API 或更新安装协议变化。

DeepSeek Harness 为第三个固定 Runtime，设置与员工选择复用现有受认证配置，控制台使用共享名称和原生会话 ID；不新增宿主桥或 renderer 能力。外部 DeepSeek Harness 从私有 Trace 普通文件加载适配桥，不读取 ASAR。

任务协作共享角色消息读模型：隐藏平台事件行；错误中断禁用协作输入，重试原员工。每轮 Trace.inputMessageId 与 Message.startMessageId 关联，点击“本轮控制台”加载该轮并展开、滚动定位提示词，即使该轮日志超过分页限制。新任务统一显示“进行中”。

任务详情移除独立问题清单与风险数角标，问题、处理过程和核验结论全部通过角色协作消息阅读；共享 renderer 和手册图同步。

任务详情的任务描述与工作目录标题同为 12px，正文同为 11px。私聊控制台入口 aria-expanded、群聊选中员工入口 aria-pressed 对应品牌蓝 --accent，关闭后恢复普通色。目录/文件首次读取以小型旋转指示与无障碍状态表达，刷新按钮保持“刷新”，不显示“读取中/正在读取”正文；错误提示和重试保留。 沟通失败按钮调用现有认证重试接口，不创建新员工或会话目录。

紧凑协作行仅通过 padding-block 设置 12px 垂直间距，保留共享样式对待答复澄清卡片的 12px 水平内边距，避免时间、正文和操作紧贴状态色条。

员工卡片桌面紧凑样式保持头像、姓名、类型/状态三列顶部对齐，与共享 renderer 同义；仅布局变更，无新增宿主接口或 CLI 协议。

自动化导航与外观隐藏偏好同步注册，宿主蒙版使用时钟 SVG；仍使用同一认证子服务和共享任务详情，无新 Electron IPC 或通用宿主桥。定时执行仅在本机客户端服务运行时触发，离线错过不补跑，详见 docs/27。

任务详情成员控制台按钮跳至对应成员；列表最多十行后滚动，成员编辑保留冻结历史。
