# AgentForge 功能实现与性能审查（2026-11-06）

审查对象：`v0.1.6-beta.1`，源码提交 `ebaff319064eb5ab26b5ae5157106dbfb4219d35`。范围覆盖任务、协作、并行执行、自动化、沟通、员工/角色/团队/工作流、插件/MCP、历史、工作目录、控制台、设置、CLI、桌面更新和持久化。本轮只审查并发布现有功能，不混入性能重构。

## 结论与证据边界

当前主要业务能力已有实现，不能把“已实现”理解成“大数据量下已达到性能目标”。最先需要处理的是共享状态保存、事务复制、历史索引同步和全量查询；这些问题会同时影响多个页面和正在执行的员工。插件/MCP 列表已经使用 SQLite 分页，不能再归因为“每次进入市场都扫描全部插件文件”；详情、绑定和执行准备仍有文件扫描成本。

下文区分：**实测**（隔离合成数据测得）、**代码确认**（路径与增长方式确认，未给出生产耗时）、**待压测**（触发条件存在，实际影响待专项验证）。全部测试数据为合成数据，没有读取或改造真实任务数据库；没有在审查中启动付费模型。耗时不是生产 SLA，不是 p95。不能仅凭静态扫描保证已经发现所有性能问题。

## 隔离基准

Node 24.7.0；同一台 Mac；主要数据文件放在系统 `/tmp` 所在内置卷。每项同步操作重复 3 次取中位数，启动测 1 次；对象转为 JSON 的耗时不计入 Store 查询计时，因此 HTTP/渲染实际成本会更高。大样本有一半消息和 Trace 集中在一个长任务，用于暴露长任务路径。扩展为合成元数据，不能代表真实插件文件扫描成本。后台开发/打包活动可能造成抖动，未建立独占实验环境。

| 样本 | Task/Run | Trace | 任务消息 / 事件 / 沟通消息（各） | 会话 | 插件目录 | 自动化 / 触发 | JSON 状态 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 小 | 50 | 500 | 1,000 | 10 | 100 | 10 / 500 | 2.21 MiB |
| 中 | 500 | 5,000 | 10,000 | 50 | 1,000 | 50 / 5,000 | 22.16 MiB |
| 大 | 2,000 | 20,000 | 40,000 | 200 | 5,000 | 200 / 20,000 | 89.04 MiB |

| 自动化列表一页 | 0.19 | 3.24 | 40.06 |

| 新增事件期间定时器延迟（单次） | 5.62 | 64.68 | 277.49 |

大样本长任务 summary 为 **20,843,427 字节**；中样本为 **5,218,412 字节**。返回名称叫 summary 并不意味着内容足够小。大样本整个进程观测 RSS 约 1.31 GiB，但同一进程顺序生成三个样本，包含夹具和 GC 残留，**不能归因成应用稳定驻留内存**。

历史 `list_sessions(limit=20)` 另测：小样本首次 249 ms、后续 15–30 ms；中样本首次 2.88 s、后续 257–288 ms；大样本首次 15.19 s、后续 3.51–4.51 s。返回只有约 1.7 KB。主要成本在同步索引而非结果体积；首次建索引需与后续查询区分。

补充磁盘观察：同一脚本在仓库所在外置卷运行，出现明显 I/O 抖动（大样本启动约 133 s、一次插件查询约 60 s）。内置卷插件查询约 1.7 ms，因此不能把前者认定为插件 SQL 本身的固定耗时。慢磁盘会放大同步主线程 I/O 的影响。发布检查也出现子进程启动超时，需以最终复跑记录为准。

原始脚本与测量结果只保留在忽略的 `.data/performance-audit-20261106/` 和系统临时目录，不提交数据库或日志。

## 建议实施顺序

1. **先 P01/P02/P03**：将频繁保存和历史索引同步从全量主线程工作改为增量；这是跨任务、沟通、配置页的共同根因。
2. **再 P04/P06/P08/P09**：后端真实分页、摘要与增量事件，统一 App/CLI 契约；先保证网络和 renderer 不拿到超大结果。
3. **然后 P12/P13/P14/P15**：文件、Git 和扩展版本索引及缓存；保留完整性和历史不变性。
4. **最后 P05/P07/P10/P11/P16–P22**：轮询、并发预算、渲染和资源生命周期治理，并用中/大合成样本建立回归基线。

建议验收指标应先建立独占、可重复基线，再由产品确定目标；不要仅以减少某个定时器频率掩盖全量计算。核心执行优化须再跑真实 Provider 完整任务到人类验收；本轮合成压测不替代该验收。
