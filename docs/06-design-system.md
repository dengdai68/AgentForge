# 界面约定

工作目录页签行移除下分隔线，当前文件/CHANGE 共用右侧无边框刷新图标；CHANGE 移除更改计数工具栏，对比布局/范围移入文件预览标题右侧，与当前文件保持同一标题结构。刷新忙碌/失败恢复及原文件选择语义不变。共享弹窗改用原生 dialog 维护键盘模态与焦点返回，表单仍仅显式关闭；统一 Runtime 同行字段、设置选中态、主题预览和语义焦点 tokens，移除弹窗硬编码阴影并支持减少动画。桌面维持紧凑尺寸，粗指针操作使用 44px 点击区。仅界面/交互变化，无 App/CLI/HTTP/Store 契约变化。

配置表单复用现有 form-field：员工简介与每行一个能力标签分开，团队编辑增加状态选择，工作流依赖节点和交接来源使用两个独立多选框；交付定义可空。任务验收标准放可选折叠区，保持底部成员/工作流和提交操作可达。

任务成员与群聊成员使用 createEmployeeMultiSelect，团队候选只展开为员工标签，已选项显示在同一输入边框中，重复员工去重；经理冲突候选禁用且说明原因。团队表单同样使用框内多选，不单独要求经理。群聊右侧成员列表/详情和最右控制台复用 tokens 与共享日志 renderer，窄屏支持关闭和键盘焦点归还。

协作读模型以消息/事件为主线，按 sourceMessageId 或唯一的已有定向消息、Dispatch/Trace 引用关联真实派工；不按正文、名字或时间猜测，不回填历史。deliveries 明示投递当前状态，history 保留每次执行与重试的实际时间，经理协调为全流程范围。CLI 保留完整投递/执行事实、验收关联及有界文件 ID/名称引用（files 最多8项、fileCount 为总数）；完整文件列表用 artifacts 查询。已知员工交接结果信封从 rawResponse 提取已记录的报告正文，去除重复结构化结果，原始消息和控制台事实不变。客户端协作区展示成员总结、沟通和关键人类状态，保留单一“本轮控制台”入口；不自动附加投递状态、技术失败/重试通知、验收文件清单或平台验收说明。长消息全文一次渲染 Markdown，超过10行仅收起区域，展开不重建 DOM，Run 内保留阅读状态。控制台无顶部错误摘要，失败记录在日志内标红；员工状态按自己的最新 Trace 显示错误/执行中/正常，重试成功后清除旧错误。未验证事项保留员工原文，不自动判定交付质量；存储、调度、模型输入和人类确认规则不变。

协作记录只展示员工、经理、人类之间的沟通 Message；系统提示、启动、投递、重试和结算事件不作为记录行。底层不可变事件、Dispatch 和 Trace 继续保留，关联执行元数据供查询。消息保存本轮 `startMessageId`，对应 Trace 的 `inputMessageId`；“本轮控制台”按该 ID 打开、定位本次提示词，不受日志分页影响。成员原生会话贯穿任务且彼此隔离，每次执行拥有独立输入轮次 ID。 新任务与经理协调统一显示“进行中”，错误显示“错误中断”；错误期间禁用输入框与 @，保留原员工重试入口。

工作目录按完整真实路径组织，当前文件按需展开与分页继续加载，CHANGE复用同一层级/图标并保留删除项；目录加载/错误/重试只属于该目录，不因全树重建切走文件选择。大文件仍提供元数据与下载。

插件自动更新控制集中在设置的「更新」分类中的插件更新模块，开关、周期和保存/立即检查采用现有表单样式；市场不混入运行设置。后台状态刷新不覆盖未保存输入。沟通初次无选择时显示最后更新会话；任务控制台初次无选择时显示最近开始执行的成员，之后尊重显式选择，不因刷新跳转。

人类协作记录靠右，时间、类型、收发人及状态置于正文气泡外，类型和收发人右对齐；正文气泡上下 10px、左右 12px 内边距，不强设最小宽度，首尾段落不额外留白。已知成员的 @提及使用与成员名称一致的深色粗体，不改变路由或 Markdown 代码/链接内容。员工消息仍靠左。

协作流只按真实消息时间展示经理结论、交接与后续提问，不在列表末尾附加固定的验收说明副本。确认完成仍是顶部独立的人类操作；不展示「停止答疑」，未归档任务保留输入，归档后只读。删除被进行中的答疑阻塞时提示等待答复，不引导不存在的界面入口。

任务和沟通控制台不平铺无正文的开始/保存、普通会话连接、空 Provider 进度或诊断占位通知。保留正文、思考、工具、提示词，以及失败、重试、取消、会话重建和恢复；未知消息不默认隐藏。完整原始事件与详细诊断仍在原有审计/日志中，不改变执行状态、分页或 CLI/API。

团队、工作流保留语义页标题，与员工一样提供同行搜索/创建按钮；按名称和说明过滤后分页，输入回第一页。目录工具栏为紧凑 44px、上移操作区；客户端使用留白连接列表，不添加列表顶边框。任务中心使用同样的顶部导航，搜索名字段有界收窄，搜索/重置/归档历史/新建任务按此顺序同排，窄屏自然换行。搜索区与列表外缘左右对齐，二者之间仅8px留白；列表不再额外横向内缩，当前任务、空搜索和归档列表保持一致。筛选草稿和按钮焦点不被刷新销毁。

任务和沟通控制台共用同一 renderer/hydrator：本次提示词完整展开已脱敏系统指令和本轮输入，下面显示对应已确认 Claude Code/Codex 原生会话 ID，未记录时如实标注。移除长快照说明和工具审计详情；截断/缺失仍明确提示。同一工具调用的重复阶段和相同公开输入不重复展示，不合并不同 ID 的真实调用。空 tool_progress 通知隐藏。侧栏、Dock 和安装包使用用户 A 图标的同源派生资源，菜单栏单独使用无底板单色模板。

沟通控制台顶部工具栏只放「最新」「刷新」，不重复员工姓名；单个成员不渲染选择标签，群聊的成员切换和历史分页入口放在工具栏下方，不占顶部工具栏。保留成员查询、错误显示和阅读状态，不变更执行协议。

插件/MCP 卡片和详情复用员工头像形状与五色 palette，按稳定安装 ID 配色。沟通输入仅保留可访问名称，不显示冗余「消息」标签；附件添加、待发移除、下载支持键盘。列表只标记真实 unreadCount，移除 pending 点。控制台文字入口有 aria-expanded，是聊天标题栏右上角的唯一开关，右侧展开与聊天各占一半；分隔线贯穿标题栏顶部和内容，右侧直接展示成员选择和日志，不重复标题或收起按钮。沿用任务详情侧栏的展开/收起交互，开关不销毁输入框。窄屏仍各半，缩短会话列表并约束整体高度，使发送按钮可见；面板内部滚动、文件名省略但不撑宽。工具/思考/正文复用任务控制台格式化。

员工插件/MCP 下拉不长期遮挡下方字段：鼠标移出选择区或焦点离开搜索/候选区时收起，点击表单其他区域也收起。鼠标从输入移动到候选项（含间隙）不能提前消失；复点输入重开，方向键与 Enter 选择，Escape 收起并保留编辑框，隐藏候选不遗留不可见焦点。收起不清空查询或更改员工选择。

员工、插件、MCP 卡片为名称和三行简介预留固定高度，员工的 Runtime/状态、市场的版本/ID 与操作区分别对齐，不因简介空白或过长改变关键位置；卡片省略不修改原始字段，完整内容在详情/编辑读取。插件详情只让正文滚动（含概览与全部组件），组件标签吸顶，标题和底部操作固定可见；不可通过裁剪隐藏长列表，也不以限制 Skill 数量代替滚动。

员工、插件/MCP 目录使用共享卡片和 `directory-toolbar`：左侧搜索、右侧创建/手动安装始终同一行，窄屏输入可收缩；不额外显示「搜索已安装…」标签，保留 aria-label。插件/MCP 卡片保留现有摘要与详情操作，详情页的删除与关闭并排，危险操作使用应用内确认与就地引用错误，不用系统弹框。

插件/MCP 未安装、搜索无匹配、加载中和读取失败均使用卡片网格之外的独立整行状态区，不按一张卡片的宽度展示，不把读取失败误报为空市场。

renderer 与 Electron 共享真实语义和命令。优先使用现有颜色、字体、间距、焦点和按钮样式；桌面覆盖位于 `apps/electron/compact.css`。

角色侧栏入口使用继承当前文字颜色的 SVG 人物名牌图标，宽窄窗口不依赖字体字形。角色与其他可选入口一同登记在 `preferences.mjs` 的 NAVIGATION 中，外观设置可隐藏并持久保存，恢复默认会重新显示；BUILD 内全部入口隐藏时分组也隐藏。这些都是客户端展示偏好，不改变角色配置或 CLI 协议。

- 列表提供搜索、分页和明确空态；不一次平铺大型员工目录。
- 团队编辑按名称或能力搜索员工，最多显示 20 个候选；已选员工单独列出并可移除。
- 工作流详情的节点导航只显示标题，完整说明在内容区展示；编辑节点可折叠。
- 长配置弹窗宽高随视口变化，正文内部滚动，底部操作可见；小窗口切换单列。
- Markdown 通过本地 marked + DOMPurify 渲染，加载失败显示转义文本。
- Shell 保留原始换行和终端主题；Edit 差异逐行展示，不插入额外空行。
- 工作目录只有「当前文件」和「CHANGE」：两者复用目录树、目录优先排序、图标、缩进与折叠逻辑，分别展示当前文件与发生变化的文件；CHANGE 的布局与范围图标组和刷新右对齐，支持行内/左右、仅差异/完整文件。
- 工作目录使用 vscode-icons 子集，主题仅作用于工作目录树和选中文件预览。
- 当前文件与 CHANGE 的根目录按内容紧凑排列，折叠后不留分组空白。当前文件的下载位于文件预览标题右侧，刷新图标位于“当前文件 / CHANGE”页签行右侧，未选文件禁用下载；读取失败就地提示，不以导航错误页替代任务页面。
- CHANGE 不在各目录下显示「没有更改」；仅全部成功读取且无变化时展示一次整体空态，读取失败、未初始化与加载中不得误报无变化。
- 控制台、协作记录使用可用窗口宽度；日志和重内容按需加载。
- 提示词按 Trace 开始时间排列，每个调用只出现一次；分页尚未覆盖其时间时不提前固定展示，加载旧页后按时间合并，正文仍按需读取。
- 执行中成员以蓝色底色、边线及文字区分；终态恢复中性。协作使用蓝色（人类）、紫色（经理决策/咨询）、青绿（交接/答复），待答用琥珀色。状态文字保留，颜色不代表业务通过。
- 私聊/群聊沿用上述色彩，人类蓝色、员工按稳定身份使用青绿/紫色；强调姓名、已有加粗/标题和引用，正文保持中性色。桌面保留紧凑记录，使用紧凑对话呈现。
- 协作记录和沟通按实际发送者布局：人类消息靠右，员工消息靠左（包括员工发给人类的消息）；不是按“涉及人类”筛选标记判断。人类记录宽度有上限，正文仍左对齐以便阅读 Markdown/代码；保持时间顺序、回复入口和分页语义。
- 控制台不再次回显 `message.sent` 协作正文；正文在协作记录保留，Runtime 输出和失败等执行事实仍显示。任务标题左侧提供有可访问名称的返回列表图标按钮，和标题保留明确间距，返回时保留任务搜索条件。
- 控制台可见工具行无需展开即可显示 Bash 命令、Read/Write 文件路径；这三类连续调用的分组默认展开行摘要，用户仍可收起。摘要仅来自已脱敏且通过完整性校验的执行内容。成功 Read 展开显示 Done，失败保留错误；Write 展开直接呈现写入文本及脱敏/截断提示，无法解析时如实回退。
- 图标按钮具备可访问名称，选中态可辨识，键盘可以完成搜索、选择和关闭。

退出入口位于设置 → 常规底部。任务详情在协作页默认展开，在工作目录和控制台页默认关闭；任务描述显示前 100 字并可展开。

所有目录的未创建及搜索无结果共用 `.directory-empty`；不在空态重复创建按钮，入口保留在工具栏。

任务、团队、工作流、员工、角色、MCP/插件及沟通选择目录共用 `.directory-empty`，宽窄布局一致。

## 品牌颜色与目录状态

应用以用户提供的蓝/青/紫缎带 A 图标为品牌来源：主操作、选中和焦点使用 `--accent` #2558d9（悬停 #1e46b7、浅底 #edf3ff、边框 #cddcfa），青色使用 `--accent-cyan` #076b8b / #e8f7fc，紫色使用 `--accent-violet` #6b4ec4 / #f1edff。正文 #17233d、次级文字 #5f6e87，默认浅底 #f2f5fc、边框 #dfe5f1。暖白/极简仅改变中性表面，不改变品牌和状态语义。禁止为单个页面新写一套徽标配色。

员工“可用”和静态 Runtime“支持”采用品牌蓝；不支持/停用用中性文字与浅底，失败用红，待人类处理用琥珀。文字始终保留，颜色不代表业务验收通过。能力标签用中性浅底，员工/扩展头像采用同一组紫、青、橙、绿、蓝高区分度实色与白色字形，维持可读对比。

目录空态共用 `.directory-empty`：width 100%、margin 0、padding 14px 16px、1px dashed var(--line) 边框、6px 圆角、var(--surface-soft) 背景与 var(--muted) 文字；标题单独一行。左右边缘与所属列表或整行卡片对齐，在网格内须跨所有列。不得叠加 `.empty-state` 或页面级边框。加载和读取失败保留真实状态，失败使用 alert，不伪装为无结果。

## 目录与 Runtime 呈现补充

角色与其他目录共用上述整行空态。生成头像使用高区分度的紫、青、橙、绿、蓝实色与白色字形，不限于品牌色；品牌按钮、焦点与状态标签保持语义 tokens。任务中心工作区的任务 h3 缩为17px，目录标题不受影响。Runtime 为固定两行，开关表达可用性；配置默认折叠，页内展开编辑模型与思考等级；子标题字号严格小于所属设置主标题。Runtime 模型和思考等级同排；两种候选列表均距输入框4px，间隙保持可悬停，空间允许时完整展示六项；模型及思考档位仅展示标签首字母大写，原始 ID/提交值保持不变。

Runtime、GitHub/GitLab 都是所属设置标题的二级配置组；桌面使用紧凑分隔行，Runtime 上下10px、页内编辑顶部12px，仓库配置上下12px，避免层层卡片与重复大留白。表单控件、说明、焦点及分隔仍清晰可辨。任务中心操作列直接展示当前允许的启动、归档、恢复任务和删除任务，不再使用“更多”菜单；窄屏按钮可换行，删除确认和服务端可操作性门禁不变。

新建任务使用内容优先的独立弹框：标题、随可用高度在六至十二行之间调整的内容描述；输入框最高十二行，更多文字在框内滚动，弹框随内容收紧。验收标准默认折叠、可留空，收起保留草稿，无效输入自动展开显示错误。团队和流程两项位于底部同排，工作目录仅一行小字提示；不展开执行说明、经理配置或流程人员/节点详情。底部提交固定可达，短窗口由正文区滚动。字段、冻结与启动协议不变。

常规的关闭选项保持两项同排；GitHub/GitLab 的 Token 输入、保存和移除操作同排。Runtime 模型/思考等级同排，展开时隐藏重复摘要，保留字段错误与一条总提示；普通状态不再逐字段重复说明。任务详情的工作目录在「复制」后提供「打开」，由受限宿主打开当前 Run 文件夹，失败就地提示且保留页面。

实时同步状态只在侧栏底部登录信息旁展示一次，不占各页顶栏；窄窗口隐藏文字但保留状态圆点、可访问名称和悬停说明。连接及断开状态仍由实际任务事件流更新。

应用图标保留用户原始 PNG；侧栏使用清理边缘的彩色圆角图，Dock/安装包使用相同的 824/1024 图形比例及透明留白，避免图标过大或白色底板。顶部菜单栏使用独立的 18pt/2x 单色 A 模板，随 macOS 明暗背景和选中状态变色。详见 web/icons/README.md；无 CLI/API 或任务协议变化。

更新 Tab 不重复显示“更新”标题，直接以与常规/外观配置相同层级的“应用更新”和“插件更新”分组；当前版本同行附简短 GitHub 文字链接，窄屏自然换行，不单列仓库地址。应用更新的信息和按钮集中在“设置 → 更新 → 应用更新”区域；自动检测结果、下载进度和下载完成状态就地更新，不创建全局通知卡或自动切换页面。区域重新打开时读取宿主最新状态，检查、下载、安装仍由现有按钮触发。
