# 公开产品演示素材

这些文件供仓库首页、首次使用教程与推广文稿引用，使用相对于文档的路径，点击后进入 GitHub 图片预览。

- `workspace-collaboration.png`：任务工作空间的经理分工与员工交接。
- `team-chat.png`：沟通中的多员工群聊与 @ 定向交流。
- `quickstart.gif`：约 19 秒的员工配置、任务创建、协作记录与工作目录导览。
- `task-create.png`、`employees.png`：首次使用教程和推广文稿的配图。

素材采自 v0.1.6 桌面客户端的隔离实例。任务、文件、协作和群聊使用公开示例数据，未调用模型；这些图片用于展示界面，不作为真实模型执行结果。未使用操作者的真实任务、聊天、凭据或私有文件。测试日志、数据库及录制脚本不属于公开素材。
